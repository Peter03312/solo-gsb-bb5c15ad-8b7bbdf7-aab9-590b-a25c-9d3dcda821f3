联排中断：停排 / 恢复（仅当前执行版）

联排中断时由舞监为当前执行版填写当日 HH:MM 停排时刻与非空原因，恢复时再填写恢复时刻。 同一版本只能有一段进行中的停排，时刻必须严格递增且不得覆盖已登记的实际开始 / 完成。 停排期间执行岗位的开始 / 预计结束 / 完成登记与新签认一律拒绝，发布新版也须先恢复；舞监更正、跳过仍可办理，但更正后的实际时刻不得落入停排区间。 恢复后：未开始项重算开始不早于最近恢复时刻，已开始未完成项的推算 / 预计结束顺延该段中断分钟；停排前有效双签失效，须双方重签后方可开始。

岗位代班（仅当前执行版）

现场临时换人：为某岗位指定一名已有执行账号代班。代班期间原岗位账号失去该岗位登记权， 代班账号获得该岗位登记权并保留自己原有岗位权限；每个岗位至多一名在任代班。 发布新版后代班不自动延续；旧版代班记录在「发布版本」回看页只读可查。

顺延变更待确认

岗位登记、舞监更正、跳过链、停排或恢复使某个尚未开始提示项的重算开始时刻变化时， 系统为该项所属岗位留下一条待确认记录（冻结版本、提示项、变更前后时刻、触发操作与时间）；未变化或已跳过项不留痕。 执行账号只能看到并确认自己当前负责岗位（含代班）的记录，确认须核对所见记录； 代班期间原账号失权、代班账号接手；版本归档或权限变化时旧提交会被拒绝。舞监可查看全部记录及各岗位未确认数；旧版本只读回看，新版不承接待确认。

现场顺延预演（舞监 · 只读假设推演）

现场顺延时，可对当前执行版的一项或多项「未开始 / 已开始且未完成、未跳过」提示项填写假设预计结束时间， 系统以同一次读取的当前版本与全部登记行版本为基线，同时套用全部假设后按现有前置与跳过规则重算， 给出逐项待执行开始 / 结束的前后差异，以及同岗位冲突的新增 / 消失 / 仍存在对照。 预演为只读操作，不更改任何登记、已发布计划、跳过状态与更正历史；执行版或任一登记行已变化时整体拒绝并提示刷新，不返回混合时点结果。

执行版复盘（舞监）

按冻结计划、现场登记与停排记录逐项复盘：实际开始相对计划的有符号分钟偏差、实际持续分钟及扣除停排后的净执行分钟 （只扣实际起止区间与已结束停排段的交集，重叠分钟只扣一次）。跳过、未开始、进行中及交接自旧版的完成项分别标识，不计入本版完成汇总； 未完成项的实际持续与净执行分钟为空。另按岗位汇总本版完成数、净执行分钟与开始偏差之和。 更正登记或恢复联排后重新打开预览即更新。确认无误后可封存复盘：携所见执行版、登记行版本与停排状态封存，任一依据变化整体拒绝；每版仅能封存一次，明细与汇总作为当时快照保存，此后不得改写。

重算规则：未开始项按前置项的实际/预计结束顺延，且不早于原计划；已开始项保留实际开始时间。 顺延导致的岗位冲突以红条提示。点击「来源」可查看任一提示项排期开始时刻如何形成： 以原计划开始为基线，达到最终约束时刻的直接前置全部列出，并逐层标明实际完成 / 预计结束 / 按时长推算； 已跳过前置不构成约束，原计划本身决定开始时明确显示无需顺延。

舞监可对当前执行版本任一行的实际开始 / 实际完成 / 预计结束进行一次单项更正或清除并填写原因； 更正只改现场登记，不改已发布计划；归档版本禁止更正。每次更正均留有前后值、操作者、时间与原因的记录。

某项无法执行时，点该行「跳过链…」可预览触发项及沿前置关系可达的全部后继，填写非空原因确认后将整条依赖链标记为跳过： 链中任一项已有实际开始/完成（或预览后登记行变化）将整体拒绝、不留部分标记；首次跳过清除预计结束、保留已发布计划并记录操作者与时间； 已跳过项只展示、不重复留痕，执行账号不得再登记，舞监不得更正其时间。跳过项不计入待执行时段与岗位冲突； 仅当前执行版可操作，新发布版不继承跳过状态，旧版回看可见原因。

标记「需放行」的提示项须双人放行：当班执行人「签认就绪」+ 舞监「签认可执行」两类有效签认齐备后，岗位才能登记实际开始（预计结束与完成登记不受影响）。 每次签认记录签认人、时间及目标与直接前置项的登记行版本；目标或任一直接前置项的登记行变化、代班变更导致签认人失去登记权，都会使旧签认失效（需重新签认）。 签认状态与失效原因显示在「放行签认」列；新发布版不继承签认，历史版本可只读回看签认记录。
